# 长文本配对比较：旧baseline与20轮长样本加权实验

2026-09-22，比较旧10轮Stage 2最终导出与20轮Stage 2长样本加权最终导出。各自使用学习得到的voice，speed=1；整段生成，不分句、不截断。结果不能分离延长训练、采样策略以及voice变化各自的贡献。

每种语言选验证集中token最多的4条，另加1条新写的四句探针：共15组、30条完整合成音频，全部通过LITs ASR与音质评分。完整输入为168–441 tokens，英文最长验证样本仍为单句；本次不覆盖超过模型510 token限制的整篇文章。

|---|---:|---:|---:|

| DNSMOS总体评分 | 3.498→3.482 | 3.498→3.493 | 3.495→3.497 |

首句对照使用完全相同的音素前缀，分别单独输入与放在完整上下文中；预测帧数排除BOS/EOS。它是模型时长诊断，不是人工标注的声学切分。英文只有一组适合这个对照，不可视作稳定的语言总体结论。总音频时长也包含停顿，不能直接解释为发音速度。

中文/混读首句缩短略有减轻，但改善不一致：11个首句配对中，部分变好、部分变差；最明显的中文样本仍缩短17.3%（原19.6%）。四句中文探针仅从−10.7%变成−10.5%。这批小样本不支持“长文加速问题已修复”。中文/混读的CAMP相似度有所增加，DNSMOS整体接近。

逐条ASR显示中文错误主要为同音字等，两模型错误数相同；英文错误减少一处；混读新模型一条转写出现“它俩→他俩”及“我我→我”的差异。ASR可能自行规范化重复词，不能据此确定音频实际漏读。没有据此做人工听感结论，也未做显著性检验。
